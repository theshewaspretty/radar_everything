radar_everything

GitHub 스타 · MCP 서버 · 취약점(CVE) 신호를 주간·월간·연간으로 모으는 확장형 오픈소스 레이더. 소스는 플러그인으로 추가하고, Docker 한 줄로 로컬에서 바로 켭니다.

한 레이더, 여러 신호

기본 소스 3종을 같은 주/월/연 타임라인으로 탐색합니다.

GitHub

기간별 공개 저장소를 star 기준으로 랭킹. Search API + Trending fallback.

MCP Servers

Model Context Protocol 서버를 star·registry 메타로 수집합니다.

Vulnerabilities

보호나라(boho.or.kr) RSS와 NVD CVE/CVSS 심각도를 함께 보여 줍니다.

Plugin sources

BaseCollector 구현 후 registry에 등록하면 새 소스가 UI·API에 붙습니다.

Quick Start

Pages 데모 앱에서 UI와 샘플(및 GitHub 라이브 조회)을 바로 체험할 수 있습니다. 스케줄러·취약점 RSS·DB까지 포함한 풀스택은 Docker로 실행하세요. 

git clone https://github.com/<your-account>/radar_everything.git
cd radar_everything
cp .env.example .env
# GITHUB_TOKEN=ghp_...  (권장)

docker compose up --build -d
# → http://localhost:8080
